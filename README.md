# A-Study-On-RISK-AND-RETURN-ANALYSIS-of-MARUTI-SUZUKI-INDIA-
Conducted a five-year risk and return analysis of Maruti Suzuki (2020–2024) using historical stock price data from Yahoo Finance and Investing.com. Calculated monthly returns, average returns, and standard deviation to evaluate volatility, financial performance, and the risk–return relationship, supporting informed investment decisions
